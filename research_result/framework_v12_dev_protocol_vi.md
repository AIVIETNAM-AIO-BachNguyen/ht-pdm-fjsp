# Prelocked V12 scratch RL DEV protocol

Locked after audited V11 gradient result `aa97a71` and method clarification `e86e402`, before V12 implementation or outcomes. Hypothesis: fixed paired-scenario uncertainty attenuation improves **self-consistent H64** root-action credit compared with the same-compute plain Q update. It tests reliability of the H64 update, not a repeated self-versus-risk continuation. V10 and V11 outcomes are opened design evidence; no TEST is used.

Arms: `reliability_credit` (proposed) and `plain_credit` (same four common scenarios and Q banks per arm, unweighted joint advantage). Both use V10 free shared-edge actor, all legal matchings, λ=0.5 conditional assignment term, Adam 3e−4, five epochs, minibatch64, KL penalty1/hard limit0.02, return scale10. Training: seeds 71500000–04, six iterations, 16 on-policy episodes/case/iteration, 64 selected legal-multi-action states/case using fixed 22/21/21 clock-bin quotas. At each state/root use four common stochastic event and policy-uniform scenarios with old-actor continuation to H48 and fixed risk tail through H64; store per-scenario root costs, bank seed, state and update trace. Iteration1 actors/tapes identical across arms. No warm-start, imitation, threshold or hard service shield.

Selection: each arm/train seed chooses minimum four-case mean cost over iterations0–6 on fixed DEV physical seeds71510000–15, ties earlier. Cases: interchangeable scale1, reciprocal scale2/3, specialist/generalist scale2. Evaluate selected actors on same DEV seeds with locked V7 flat/shared/canonical, FCFS, risk matching and bounded rollout. Primary: case-balanced objective, paired arm difference with hierarchical 95% bootstrap across five train seeds and 16 physical tapes; per-seed and per-case differences. Secondary: availability, H failures, CM/PM queues, cost parts, pending/starts, selection/wall time, forecast transitions, action attenuation weights and Q spread, training instability/selection iteration. If average gain is not ≥10 cost units, not in ≥4/5 seeds including all three strongest plain-control seeds, or candidate is >1.02× rollout, <10× faster than rollout, or risk is no worse and no slower, **no DEV promotion**. Overall user A/B standards remain stricter and require fresh confirmation plus independent replication; even promotion is not completion.

Fresh registry defines disjoint train/DEV/smoke/forecast/bootstrap seeds and checks historical registries. Hard timeout 20min smoke and 4h full; run new UTC timestamped directory, refuse overwrite, retain partial on failure, tqdm training/Q/eval. Source/protocol/registry/tests committed and pushed after tests+Ubuntu smoke, before full DEV. Manifest records git/source/checkpoint/comparator hashes, exact seeds/params/status/counts; CSVs store Q samples and training/evaluation grids, selections, aggregate summary. Independently rederive selected Q banks and all learned selected episodes, source grid, weights and bootstrap before reporting. No TEST, SSH or rsync.
