# V10 assignment-credit scratch-RL DEV protocol

Locked 2026-10-20 before V10 implementation or outcomes. Proposal: `method_v10_proposal_vi.md`. Exploratory fresh DEV only. Frozen V7 simulator/cases/requester/objective/mask/H48+tail16 and same 1,597-parameter V7 shared-edge actor with free legal matching set in both arms. Primary contrast: V10 all-action expected-gradient **plus** equal-machine-set within-assignment counterfactual term (λ=0.5) versus otherwise identical all-action expected-gradient ablation (λ=0). Both have the same actor parameterization and complete two-scenario Q bank. No hard shortest assignment mask, teacher/planner labels or altered objective. Baselines on equal-information physical tapes: immutable V7 flat/free and shared-canonical selected models, FCFS, risk matching and bounded rollout (16 scenarios, six ticks, risk continuation).

**Seeds and budget.** Five new independent actor/training seeds 70400000–04, paired initial weights and arm-independent physical seed derivation; new DEV physical seeds 70410000–15 for every case; forecast anchor 70420000; hierarchical bootstrap seed 70440000; smoke seeds 70490000–01. Check all against earlier seed registries and no train/DEV collision. Six fixed updates plus iteration0. At each seed/iteration/arm collect 16 stochastic source episodes per case (64 total, H48) and hash-select 22/21/21 states from tick bins 0–15/16–31/32–47 per case, up to 256 selected states. Compute every legal root's H+tail Q with two common failure/policy-random scenarios under the current actor. Same scenarios and full Q-bank cost for both update arms; diverged policies may visit different states after first update. Expected-gradient and assignment term use return scale 10, Adam 3e-4, five deterministic shuffled epochs, minibatch64, KL penalty1 and rollback/stop if batch-updated mean KL>0.02. Tie rules, action sampling, source/tape provenance and exact full-objective checks follow V9. Record all Q banks, learning trace, KL, entropy, update counts, physical/forecast transitions and wall/CPU cost.

**Checkpoint and comparator evaluation.** Evaluate all seven checkpoints per arm/seed/case on all 16 fresh DEV physical tapes. Select the checkpoint for each arm/seed by four-case mean cost, tie to earlier iteration, before examining selected competitive summary. Evaluate both selected V10 arms, V7 flat/free and shared-canonical (five immutable original training replicas each), FCFS, risk and bounded rollout on identical DEV physical seeds. Equal-weight case mean over four cases, then training/physical seeds. Pair V10 arms by training-seed identity and physical tape; use 20,000 hierarchical bootstrap draws over five training seeds and 16 physical seeds shared across cases. Comparator training seeds are separate and not paired by identity. Report per-seed/case objective, cost components, availability/failure/queues/starts/pending, decision time, forecast/training compute, invalid actions, conservation and timeouts. Diagnose assignment, subset and WAIT actions on selected trajectories if the gain is material.

**Prelocked gate.** V10 advances to separate fresh TEST prelock only if assignment-credit versus λ0 ablation improves equal-weight cost by at least 10 units, wins ≥4/5 training seeds with at least 3 strong-replica improvements (strong defined by λ0 control being in its three cheapest seedwise costs), is ≤1.02× the bounded rollout DEV cost, has ≥10× faster mean selection than rollout, and risk matching does not dominate it in both cost and speed. This DEV gate is stricter than V9's weak-seed rescue. If it fails, preserve all negative raw results, audit and explain; do not relabel a heuristic overlay as RL or reuse this DEV as fresh confirmation. Final goal still requires unchanged criterion A (≥5% cheaper than strongest locked baseline) or B (≤1% planner cost with ≥10× speed and no simple heuristic dominating both), five-seed uncertainty, independent replication, fresh TEST, per-case/compute/failure report and pushed provenance.

**Workflow/artifacts.** Focused tests plus new Ubuntu smoke, commit/push verified code/proposal/protocol/seed registry before full run. tqdm for source collection, counterfactual states, DEV selection and comparison. Hard 3h DEV/10min smoke stop, no adaptive extension. Each run has a new UTC timestamped `research_result/framework_v10_{smoke|dev}_.../` path and refuses existing paths. Save manifest with source commit/hashes/config/runtime/status/seed streams/checkpoint hashes, full Q trace, training trace, checkpoint grid, selections, episodes and summary; raw/checkpoints outside Git. Independent audit of seed/grid/source hashes, samples/Q banks, action legality and objective/conservation, checkpoint selection and bootstrap before compact report is pushed. Preserve all existing user edits and old artifacts. No SSH or rsync.
