## Root value probe and decomposition

At each selected state, obtain threshold-admitted legal actions. Use the same bounded current-information rollout as the V7 planner (16 forecast scenarios, horizon6, risk-matching continuation) to score **every legal root matching** with one common scenario bank. Smoke uses 4 scenarios. No realized future tape enters policy/planner. Compute:

- Full root planner best, and best legal action under the V7 canonical shortest-duration mask, with deterministic baseline-first tie rule as in `choose`.
- Source policy's selected root, same-seed other learned arms' roots, and risk-matching root on the **same** state. Record bounded root-score regret relative to full best.
- Exact decomposition for canonical source: full regret = `score(chosen)−score(best canonical)` (actor selection gap) + `score(best canonical)−score(best full)` (mask restriction gap). For other sources mask gap is zero. Report counts with positive gaps and thresholds ≥1, ≥5, ≥10 cost units, per arm/case/training seed and clock bin; ties retained explicitly. This is forecast-root value, not closed-loop economic cost.
- Mismatch taxonomy: source WAIT vs planner service (under-service timing), source service vs planner WAIT (over-service), same machine subset/different technician (assignment), different subset (priority), and cardinality difference. Classes are mutually exclusive in this order, with cardinality a separate attribute. For canonical source also count when planner best is excluded by the heuristic mask and when simple risk action beats source under the same forecast bank.
- Actor/critic information is not conflated; all three learned policies share the same 56-D observation contract. Report per-source closed-loop H+tail cost, H starts/availability/failures and selection compute on these diagnostic physical seeds as descriptive context, but do **not** claim confirmation from this DEV panel.

Assess whether weak canonical training seeds 02–04 have larger actor-selection or mask gaps than strong 00–01 on their own states and common states. If mask gap dominates, a method must replace/revise heuristic assignment restriction. If available-action actor gap dominates and flat/risk choose better on the same states, investigate representation/action scoring and credit. If bounded planner root regret is too small to account for the large full-episode cost gap, test longer temporal effects before architecture changes. No single DEV number selects a final method.
