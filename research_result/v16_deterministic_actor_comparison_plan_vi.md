# V16 exploratory deterministic-actor Q comparison — analysis plan

This plan is written after reading the V15 audit's published alpha=0 mean deterministic V14 Q (699.845) and the audited V16 post/pre held-out Q means (695.555/696.258). Thus the aggregate signs/magnitudes are **already known**; this is a transparent retrospective DEV comparison, not a blind preregistered gate, fresh confirmation or method result. No new model, physical seed or simulator tape is opened.

Question: does each held-out V16 value head improve saved old-policy H64 Q over the deterministic count actor's choice, rather than merely over `source_action`, which was sampled for V14 on-policy collection? Join the already independently audited V15 rows' alpha=0 actor action/Q to every V16 held-out root/start by training seed, update, case, physical seed, tick and rank. Assert root Q/legal equality and alpha0 Z/B choice equality. Primary descriptive quantities: post−deterministic and pre−deterministic Q, equal-weight average over three optimizer starts then each 64-rank × six-update × four-case cell × five training seeds. Report per case, seed, start, changed actions, selected WAIT, and deterministic regret to best saved Q. Compute paired hierarchical percentile CI95 with 20,000 resamples and fixed analysis seed 72950004: resample five training seeds and 64 ranks within update/case, averaging starts before bootstrap. This CI describes opened-bank uncertainty; it does not correct for method search or prove closed-loop performance.

No success gate is set after seeing the aggregate means. Interpret target-case/seed heterogeneity, four-scenario old-actor continuation bias and the old V14 training state distribution. A material and broadly distributed gap would motivate a *new* prospectively locked scratch-RL credit/optimization proposal with equal-capacity and compute controls, not retroactively validate V16's post-release feature. An absent or concentrated gap would weaken that direction. Save a timestamped `research_result/v16_deterministic_actor_comparison_dev_*` directory containing joined rows, summary and hash manifest; independent audit checks join/Q/bootstrap against both source artifacts. Run with tqdm and a 10-minute timeout. Commit/push plan and code before calculation. No TEST.
