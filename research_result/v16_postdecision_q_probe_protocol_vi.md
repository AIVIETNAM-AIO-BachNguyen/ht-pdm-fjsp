# V16 post-decision compatible-release Q probe — prospective lock

Locked before V16 implementation or any V16 Q prediction. This is a supervised **screen on already opened DEV training states**, not a scratch-RL ablation, closed-loop evaluation, replication or TEST. It cannot satisfy the user's research goal by itself. Source: independently audited V14 `count_calibrated` H64 old-policy root Q banks, five seeds 72600000–04, six updates, four cases, 64 ranked states per cell (7,680 states). Each root bank uses four common stochastic scenarios. Do not open fresh physical seeds.

## Hypothesis, controls and data

The matching-conditioned post-decision technician release vector helps a learned full-matching value head choose lower saved old-policy H64 Q than an equally sized head with pre-decision release features. Both heads receive the same 56-D current observation, 8-D matching incidence and 4-D started-machine flags. Their final 6 channels are either: (post) two worker release times after starting matching service and four earliest compatible worker releases, or (pre) the corresponding six release times before dispatch, repeated over every action. Thus both have identical input shape, parameters and legal-action support; the control can infer post times from state and action, so the contrast tests an inductive bias rather than privileged information. Divide release times by 12. For each machine, earliest subsequent opportunity is `max(1,min compatible worker release)`; this applies identically to both arms. Only current state/configuration and action enter features. No Q, future tape or planner result enters the features.

The fixed action network is `Linear(74,64)-ReLU-Linear(64,64)-ReLU-Linear(64,1)` (9,025 trainable parameters), shared across all legal actions. Inputs/normalization, architecture and gradient-active capacity match exactly. Fit each arm independently from the **same random initialization** within fold/start. Use five leave-one-training-seed-out folds and three paired initialization seeds 72950000–02. These are optimizer seeds only, not simulator seeds or a new TEST. Fit on the four other seeds' 6,144 root states; never use held-out fold states for fitting, checkpoint selection, normalization or tuning. Fixed six epochs; Adam learning rate 0.0003, batch 256 states, weight decay 0, gradient clip norm 1, shuffled by the paired optimizer seed and epoch. All legal actions enter one masked listwise cross-entropy: target distribution `softmax(-Q/10)` over legal actions, model distribution `softmax(-score)`; lower score means lower predicted cost. No Q interpolation or data-dependent early stopping. All inputs are finite float32; Q is converted to float32 only for target softmax. Report training loss by epoch. One fixed CPU thread to improve repeatability. Do not tune on held-out scores.

## Metrics and gate

For every held-out state/start/arm, pick the minimum predicted score among *all* legal matchings, tie to lowest catalogue index; use the saved Q for that chosen action. Primary paired estimand is `Q(post)-Q(pre)` averaged over starts, states, updates, cases and the five held-out training seeds, equal weight per cell. Negative favors post-decision features. Hierarchical percentile CI95: 20,000 draws, seed 72950003; resample five training seeds, then 64 state ranks within each selected seed × update × case; average the three paired starts within each state before resampling. Also report fixed-start sensitivity rather than treating three optimizer starts as independent physical seeds.

A **go-to-scratch-RL diagnostic signal** needs all: mean delta ≤−1 economic Q unit/state, negative fold mean on at least four of five training seeds, CI upper <0, changed chosen action in ≥1% of paired state/start comparisons, post-arm Q at least 1 unit/state below the saved source action Q, and post-arm WAIT rate with a legal service action ≤ the saved source WAIT rate +2 percentage points and ≤10% absolutely. The source-action comparison is descriptive if `source_action` is a sampled rather than deterministic V14 action; the gate still uses that recorded action. A pass only warrants planning a fresh scratch-RL campaign, never a performance or novelty claim. A fail retires V16's release-conditioned-value direction absent genuinely new evidence.

Secondary: per seed, case, update and optimizer start Q delta; root regret above best saved Q, absolute saved Q for each arm/source, decision class (WAIT, machine set, assignment), legal count and selected action differences, WAIT counts/rates when service legal, training loss and inference time. Flag nonfinite outputs, illegal actions, paired capacity mismatch and near ties; any such integrity failure invalidates the probe. Report that saved Q follows V14 count actor and has only four scenarios; offline root value need not predict closed-loop learning.
