# Maintenance coordination RL research

This directory holds new results for the current lab research goal. Each smoke
and full campaign writes to a new UTC timestamped subdirectory. Raw episodes,
checkpoints, and logs in those directories stay outside Git; compact reports
are committed here after verification.

The framework v1 protocol is `docs/maintenance_framework_v1_protocol_vi.md`.
Its first smoke run was an engineering check only and must not be interpreted
as a scientific learner comparison.
