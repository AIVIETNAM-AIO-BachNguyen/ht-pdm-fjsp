# Prelocked V8 DEV representability probe

Locked 2026-10-20 before implementing/running this probe. Exploratory analysis of the independently audited V8 headroom DEV states, not an RL method or new confirmation. No TEST use, simulator change, teacher-pretraining claim or checkpoint selection.

**Question.** Is the V7 additive local-edge actor structurally unable to express economically material *current-request* planner preferences on reachable states, or are its weak training seeds more consistent with optimization/credit failure? V8 headroom attributed nearly all canonical root regret to available-action choice, but this alone does not distinguish expressivity from learning. The earlier V5 fixed post-decision capacity term failed; do not repeat it as the next method.

**Input and exact collision definition.** Use all 720 hash-selected states in immutable `v8_headroom_dev_20261020T052426Z/states.jsonl`, whose forecast values were independently audited. Reconstruct the 56-D present observation from stored state, submissions, case and tick. For each pair of legal actions `(a,b)` with a common state, form the multiset of *signed* edges in their symmetric difference (positive in a, negative in b). V7 score difference is a sum of per-edge functions of (clock2, machine8, worker first2, edge2); common edges cancel. A collision comprises two state/action-pair records with the same signed edge identities and exact float32 input bytes for every involved edge, but different remaining context. If the six-tick planner strictly prefers a in one state and b in the other, with absolute root-score margin ≥5 in **both**, no deterministic V7 additive local-edge actor can realize both preferences. Count pair-record collisions, unique state pairs and total source-state coverage; report by case and source training seed. Also count margin≥1 and ≥10 sensitivity. Demand exact byte equality; no approximate/rounded collisions.

**Supervised capacity check (secondary; only if useful).** Fit from scratch V7 shared-edge scorer, a parameter-matched or clearly capacity-reported global joint-action scorer, and the standard flat MLP on audited DEV root values. Split by diagnostic physical seeds: optimizer-train 69100000–19, checkpoint-selection 69100020–23, final probe 69100024–31. No state from a physical seed may cross a split. Five fixed optimizer starts 70200000–04, same split for every family, full legal-action list, centered root costs as targets, masked score MSE. Maximum 200 epochs; select minimum validation MSE with ties earlier, stop at this fixed budget. Metrics: final heldout selected-action root regret and ≥5 count versus planner, risk and original V7 checkpoints on the *same heldout states*, plus validation/train MSE and per-seed spread. This is an upper-bound diagnostic for representability under planner labels, **not** an RL result or acceptable main-axis method. If data are too small or models overfit, report inconclusive; no architecture selection from a single small probe.

**Decision rule.** Material exact collisions support a concrete representation defect. If shared-edge supervised performance approaches global joint and risk despite weak PPO seeds, prioritize RL learning/credit stability; if joint-global markedly beats edge and flat in all five starts on heldout, formulate an action-conditioned competition method with a scratch-RL ablation. If evidence is mixed, do not claim novelty or confirmation. A future method still needs fresh training, strong baselines, ≥5 seeds, independent replication and the unchanged goal completion bar.

**Execution and artifacts.** Implement focused tests and a tiny Ubuntu smoke subset, commit/push verified source before all-state run. Use a new timestamped `research_result/v8_representability_{smoke|dev}_.../` directory, never overwrite; record input and source hashes, split membership, optimizer seeds/config, model parameter counts, checkpoint selection, raw/summary metrics, runtime/status. Progress via tqdm for pair census/training, hard timeout 15 min full / 2 min smoke. Independently check collision key inputs and split/metric accounting. Keep raw outside Git; commit compact findings and verifier. Failed/inconclusive outcomes remain in the journal.

**Fixed fitting specification.** Target for each legal action is minus its audited forecast cost after subtracting that state's legal-action mean (cost units); no normalization by case or gap, no teacher logits. MSE averages over legal actions within each state and then equally over states. Adam learning rate 0.001, no weight decay, full-batch gradient, 100 epochs (replace the preliminary 200-epoch maximum above with this tighter fixed cap), select by validation MSE at any epoch with ties earlier. All starts initialize Torch/NumPy from the listed seed. Global joint scorer is a shared `56 + 8 incidence -> 64 tanh -> 64 tanh -> 1` MLP applied to every catalogue action. Flat scorer is `56 -> 64 tanh -> 64 tanh -> 21` and V7 edge is its exact `EdgeSharingActor` architecture. No canonical action restriction in fitting or evaluation; legal mask only. The global model has more parameters; report counts and treat any capacity gain as suggestive rather than isolated evidence of the competition encoding.

**2026-10-20 engineering correction before interpretation.** Initial all-state run `v8_representability_dev_20261020T055400Z` exposed an implementation omission: collision groups compared signed-edge inputs but did not enforce the prelocked requirement that the *remaining observed context differs*. Identical 56-D observations with different finite-scenario forecast noise are not representation collisions. Filter every opposite-preference record pair to require unequal full 56-D float32 observation bytes. Retain the initial run as superseded; rerun tests, fresh smoke, commit/push the correction, then fresh full DEV. This does not change the threshold, sample, fit protocol or research hypothesis.
